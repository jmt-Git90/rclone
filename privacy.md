# Privacy Policy

This OAuth application is used only for personal access to my own Google Drive through rclone.

The application is not offered to other users and does not operate a public service.

Google account data accessed through this application is used only to perform file operations requested through rclone on my own devices.

The application does not sell, share, or use Google account data for advertising.

OAuth credentials and tokens are stored locally on my own device and are not intentionally shared with third parties.
